- User's mood (e.g., joyful, relaxed, adventurous, excited, contemplative)
- Destination city (specific location name)
- List of Points of Interest (POIs) with names and categories

City: Munich

- Englischer Garten (Nature)
- Viktualienmarkt (Food & Culinary)
- Nymphenburg Palace (History & Culture)

TASK:
Generate a personalized route title and description in STRICT JSON format:
{
  "title": "Creative and appealing route title",
  "description": "Engaging description highlighting the mood and POIs"
}

STRICT REQUIREMENTS:
- OUTPUT ONLY valid JSON with exactly two fields: "title" and "description"
- NO additional text, explanations, markdown, or formatting
- NO wrapping in code blocks or backticks
- Title must be 3-8 words, compelling and mood-appropriate
- Description must be a concise summary of the whole route (2-3 sentences max)
- You MUST mention EVERY specific POI from the input list in the description
- Incorporate the specific mood and city naturally
- Maintain tone consistency with the user's emotional state
- Avoid generic phrases like "amazing journey" or "wonderful experience"

MOOD-SPECIFIC GUIDELINES:
- JOYFUL: Use uplifting, energetic language with positive adjectives
- RELAXED: Emphasize tranquility, peace, and gentle experiences  
- ADVENTUROUS: Highlight excitement, discovery, and bold exploration
- EXCITED: Focus on anticipation, energy, and dynamic activities
- CONTEMPLATIVE: Suggest reflection, beauty, and meaningful connections
