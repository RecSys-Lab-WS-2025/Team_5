- User's mood (e.g., joyful, relaxed, adventurous, excited, contemplative)
- Destination city (specific location name)
- Number of trip days
- Points of Interest (POIs) organized by day, with names and categories

EXAMPLE INPUT:

City: Munich
Trip Days: 2

- Englischer Garten (Nature)
- Viktualienmarkt (Food & Culinary)
Day 2 Points of Interest:
- Nymphenburg Palace (History & Culture)
- Olympic Park (Sports)

TASK:
Generate a personalized route title and a description for EACH day in STRICT JSON format:
{

  }
}

STRICT REQUIREMENTS:
- OUTPUT ONLY valid JSON with exactly two fields: "title" and "dayDescriptions"
- NO additional text, explanations, markdown, or formatting
- NO wrapping in code blocks or backticks
- Title must be 3-8 words, compelling and mood-appropriate
- Each day's description must be 2-4 sentences, focused on THAT day's POIs only
- You MUST mention EVERY POI from each day in that day's description
- For EACH POI, provide a brief engaging description of what visitors will experience there
- Create a logical flow connecting POIs within each day (e.g., "Begin at..., then move to...")
- Incorporate the specific mood naturally throughout the narrative
- Make descriptions vivid and specific, avoiding generic phrases

MOOD-SPECIFIC GUIDELINES:
- JOYFUL: Use uplifting, energetic language with positive adjectives
- RELAXED: Emphasize tranquility, peace, and gentle experiences

- CONTEMPLATIVE: Suggest reflection, beauty, and meaningful connections
